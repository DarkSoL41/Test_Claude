# 2. Карта памяти

Игра работает в 512 КБ chip-RAM без операционной системы (прерывания и
железо программируются напрямую, стек растёт вниз от `$80000`).

## 2.1. Общая раскладка

| Адреса | Содержимое |
|---|---|
| $00000–$000FF | векторы 68000 (автовекторы прерываний $64–$7C) |
| $07000–$07DFF | процедура записи рекордов из крэка |
| $07E00–$10FE3 | **код** PHIL_01 |
| $10FE4–$111FF | переменные музыкального плеера |
| $11200–$1195F | переменные игры, таблицы анимации, **карта** `$11928` (60×24 слова) |
| $12468–$12A67 | буфер уровня (1536 байт из файла); после разбора — список красных дисков |
| $12738 … | список багов |
| $13000–$145FF | тексты меню, таблицы игроков и рекордов, строки панели |
| $14D60–$191DD | списки объектов (см. 2.3) |
| $191DE–$1A85D | адреса клеток в битмапе уровня (60×24 длинных слова) |
| $1A85E … | адреса кадров графики в листе тайлов |
| $1B1BE–$1B41F | таблица взрывов, адреса клеток взрыва Murphy |
| $1B422–$1B4D5 | зоны кликов меню |
| $1B5A0–$1B5E7 | указатели на ресурсы PHIL_02 (после релокации) |
| $1B6BE–$1B8FF | copper-листы игры ($1B6BE) и меню ($1B896), спрайт курсора ($1BCEA) |
| $1BD94–$1C593 | файл рекордов PHIL_03 |
| $1EE00–$521FF | PHIL_02 (графика, музыка, образцы звуков, демо) |
| $52000–$7EFFF | битмап уровня 960×384×4 плоскости ($2D000 байт); в меню — экран меню |
| $7F000–$7FFFF | стек |

Интро (PHIL_00) занимает $54000–$6E3FF и затирается при загрузке уровня.

## 2.3. Списки объектов

Все списки заканчиваются нулевым длинным словом; удалённый объект помечается
`$FFFF` в первом слове.

| Адрес | Имя | Запись | Поля |
|---|---|---|---|
| $14D60 | `v_zonk_list` | 4 | состояние, фаза, клетка×4 |
| $163D4 | `v_moving_zonks` | 8 | +2 индекс в списке зонков, +6 клетка×4 |
| $167BE | `v_infotron_list` | 4 | как у зонков |
| $17E32 | `v_moving_infotrons` | 8 | как у зонков |
| $1821C | `v_sniksnak_list` | 8 | см. [4.6](04-logic.md#46-сник-снаки-и-электроны) |
| $18604 | `v_electron_list` | 8 | то же |
| $189EE | `v_orange_disks` | 6 | смещение падения, клетка×4, задержка, состояние |
| $191C0 | `v_yellow_disk_list` | 4 | клетка×4 |
| $12468 | (красные диски) | 2 | клетка×2 |
| $12738 | `v_bug_list` | 2 | клетка×2 |
| $1B1E2 | `v_explosions` | $30 | 12 взрывов, см. [4.9](04-logic.md#49-взрывы-f8e6-fc10) |
