# 3. Как игра использует железо Amiga

Игра не пользуется ОС: регистры адресуются через `a5 = $DFF000`.

## 3.1. Экран

**Игра** — copper-лист `$1B6BE`:

* lowres, 4 плоскости (BPLCON0 = $4200), окно DIW $2C81–$28C1;
* выборка DDF $30–$D0 — на одно слово шире экрана, чтобы работал тонкий
  скролл BPLCON1 (значение $00FF в начале, меняется при прокрутке);
* модули $1B6: плоскости **interleaved**, строка каждой плоскости — 120 байт
  (весь уровень 960 пикселей в ширину), следующая плоскость — через 120 байт;
* указатели плоскостей ($1B6E6) указывают в битмап уровня `$52000` —
  прокрутка сводится к их изменению (`$CE62/$CE90` — на строку клеток,
  `$CEBE/$CEF2` — BPLCON1 и слово по горизонтали);
* с линии $FC — отключение плоскостей, затем панель статуса (с $FE) с
  собственными указателями плоскостей и палитрой; на панели copper меняет
  цвета по строкам (переливы).

**Меню** — copper-лист `$1B896`: hires, 3 плоскости (BPLCON0 = $B200),
640×… , смены цвета 1 посреди строки для подсветки строк списков, спрайт 0 —
курсор мыши (данные `$1BCEA`, цвета 17–19). Другие экраны (статистика,
сообщения) используют лист `$1BB7E` (hires, 1 плоскость, градиент фона).

**Интро** — три отдельных copper-листа в PHIL_00, lowres 4 плоскости.

## 3.2. Блиттер

Используется только копирование A → D (`BLTCON0 = $09F0`), маски $FFFF,
без сдвигов:

* тайл 16×16 из листа (модуль A $26) в битмап уровня (модуль D $76),
  `BLTSIZE = $1001` (64 строки × 1 слово — 16 строк × 4 плоскости);
* вариант `$1201` — 72 строки (18 пикселей по высоте, для объектов между
  клетками), `$1002` — 2 слова (объект между двумя клетками по горизонтали,
  модули $24/$74);
* очистка/копирование экранов меню, текст панели.

Перед каждой операцией игра ждёт бит BBUSY (`btst #14, DMACONR`).

## 3.3. Прерывания

* уровень 3 (`$6C`) → `vertical_blank_interrupt` ($10ABA): музыка, эффекты;
* уровень 2 (`$68`) → `keyboard_interrupt` ($10214) — только на время ввода
  имени игрока; сканкоды копятся в матрице `$10298` (1 = нажата);
* остальные автовекторы указывают на `rte` ($8444).

## 3.4. Ввод

| Устройство | Регистр | Использование |
|---|---|---|
| Джойстик (порт 2) | JOY1DAT & $0303 | направление Murphy, в меню не используется |
| Огонь джойстика | CIA-A PRA бит 7 | «взять не сходя с места», красный диск, запуск уровня из меню |
| Мышь (порт 1) | JOY0DAT | курсор меню (`update_mouse_pointer`, $91F2) |
| Левая кнопка мыши | CIA-A PRA бит 6 | клик в меню; в уровне — «сдаться» (Murphy погибает) |
| Правая кнопка мыши | POTGOR бит 10 | в уровне — пауза (приглушённая палитра, звук выключен), повторное нажатие — продолжить |
| Клавиатура | CIA-A SDR + прерывание | только ввод имени |

## 3.5. Звук

4 канала Paula: музыка (трекерный модуль из PHIL_02) и эффекты
(`sound_frame` $10104: образцы из `$1B5B0`, `$1B5B8`). Перед стартом нового
образца плеер выключает DMA канала и ждёт несколько строк
(`dma_wait` → `wait_line_change`), как принято на Amiga.

## 3.6. Диск

Оригинальный загрузчик заменён файловым (см. [1.3](01-disk.md#13-файловый-загрузчик-крэка));
управление мотором и задержки — через CIA-B PRB и таймер A CIA-A.
