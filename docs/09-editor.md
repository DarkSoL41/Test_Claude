# 9. Редактор уровней

`supaplex_editor` — отдельная программа (C++17/SDL2) для правки
`data/LEVELS.DAT`. Лежит рядом с игрой, читает те же данные: уровни — из
`data\LEVELS.DAT`, графику тайлов — прямо из `data\GRAPHICS.BIN`, так что
уровень выглядит в точности как в игре. Исходники — `port/src/editor/`.

```
supaplex_editor [--data папка] [--scale 1|2]
```

## Окно

```
┌ инструменты: Сохранить, отмена/возврат, инструменты, сетка, камера, масштаб, ▶ Играть, ✓ Проверка … ☀/☾  EN/RU  ? ┐
│ ЛКМ / ПКМ: тайлы │ все 40 тайлов в одну-две строки (ЛКМ — основной, ПКМ — второй)                                  │
├──────────────────┼──────────────────────────────────────────────────────────────────────────────────────────────────┤
│ список уровней   │                       карта 60 × 24 (стартовый экран — жёлтая рамка,                             │
│ поиск            │                       особые порты — синие, дыры в рамке — красным)                               │
│ 001 WARM UP  *   ├──────────────────────────┬──────────────────┬──────────────────────────────┬────────────────────┤
│ …                │ уровень: название,       │ стартовая камера │ особые порты n / 10          │ мини-карта         │
│ операции         │ зонки, собрать, гравит.  │ авто / X, Y      │ (две колонки по 5)           │ (если есть место)  │
└ строка состояния: клетка под курсором, тайл, параметры особого порта, сообщения ───────────────────────────────────┘
```

Интерфейс по умолчанию на английском; кнопка **EN / RU** справа на панели
инструментов переключает язык, **☀ / ☾** — светлую и тёмную тему. Выбор
запоминается в `editor.ini`. Минимальный размер окна — 1280 × 680.

## Возможности

* **Рисование**: карандаш, линия, контур и залитый прямоугольник, заливка
  области; левая кнопка — основной тайл, правая — второй (по умолчанию
  «пусто»); пипетка — Alt+щелчок или щелчок средней кнопкой; 0–9 — быстрый
  выбор тайла по коду. Сник-снак и электрон показаны первым кадром поворота,
  который рисует игра (таблицы `$1183E` / `$1189E`).
* **Выделение**: копировать, вырезать, вставлять «штампом» сколько угодно раз,
  отражать при вставке (X, Y) и на месте (Shift+H, Shift+V) — порты и
  половинки RAM-чипов при отражении меняют направление; настройки особых
  портов переносятся вместе с ними.
* **Неограниченная отмена** (Ctrl+Z / Ctrl+Y) для каждого уровня отдельно.
* **Свойства уровня** (панель под картой): название (шрифт игры: латиница,
  цифры, знаки), заморозка зонков (0 / 1 / 2), сколько инфотронов собрать
  (0 — все), гравитация, счётчики объектов.
* **Стартовая камера**: «Автоматически» (по умолчанию) — при сохранении
  редактор записывает камеру, которую покажет игра (или на Murphy, если она
  уходит за карту). Выключите — и X / Y записываются в файл так, как вы их
  задали; под ними видно, что игра покажет на самом деле (игра сама
  подстраивает камеру под Murphy, кроме краёв карты). Настройка общая для
  всех уровней и хранится в `editor.ini`.
* **Особые порты** выделены на карте и в палитре синим (красным — особый
  порт без записи). Запись появляется сама, когда ставится тайл особого
  порта, и исчезает вместе с ним; для каждого — гравитация, заморозка зонков
  и врагов; больше 10 поставить нельзя. Все 10 видны сразу (две колонки по
  5), щелчок по клетке порта показывает его на карте.
* **Проверка уровня** — кнопка «Проверка» (F7): на кнопке — число ошибок
  (●) или предупреждений (▲), либо ✓; в окне — список, щелчок по строке
  показывает клетку. Проверяется: нет Murphy / несколько Murphy, нет выхода,
  инфотронов меньше, чем нужно (с учётом электронов), рамка не из «железа»,
  больше 10 особых портов, порт без записи, мусорные записи портов, камера
  за картой, символы вне шрифта игры.
* **Стартовый экран** игры (20 × 13 клеток) — толстая жёлтая рамка с
  надписью на плашке (красная — если камера уходит за карту).
* **Уровни**: поиск по номеру и названию, переход PageUp / PageDown,
  перестановка (Alt+↑/↓), копирование целого уровня в другой, новый чистый
  уровень.
* **Игра прямо из редактора** (F5, «▶ Играть»): текущие уровни (даже не
  сохранённые) копируются во временную папку `editor_test`, игра проходит
  интро и меню сама (за секунду, без картинки), запускает этот уровень от
  имени игрока EDITOR и закрывается, когда уровень окончен (Esc — сразу).
  Ваши рекорды и игроки не затрагиваются.
* **Импорт / экспорт**: перетащите в окно файл уровня `.SP` (первые 1536 байт
  — на место текущего уровня) или целый `LEVELS.DAT` (все 111, в том числе
  от PC-версии); Ctrl+E — записать уровень в `export\LEVELnnn.SP`,
  Ctrl+P — картинку уровня в `export\LEVELnnn.bmp`.
* **Мини-карта** (справа под картой, если хватает ширины окна) с рамкой
  видимой части; масштаб 8–64 точки на клетку, прокрутка колесом / стрелками
  / перетаскиванием (пробел или средняя кнопка).
* Настройки (масштаб, сетка, последний уровень, выбранные тайлы, язык, тема,
  автоматическая камера) — в `editor.ini` рядом с программой.

## Что редактор делает сам (правила Amiga)

Всё это — выводы разбора (`docs/06-formats.md`, `docs/08-research-notes.md`):

* **Неизменённые уровни сохраняются байт в байт**, в том числе с мусором,
  который был на дискете. Приводятся к правилам только уровни, которые вы
  правили или импортировали.
* **Стартовая камера** (байты 1440–1443): записывается та, что игра и так
  покажет, если она в пределах карты; иначе — по центру на Murphy, прижатая к
  краям. PC-редакторы пишут сюда нули — с ними камера уезжает за карту. С
  выключенной «Автоматически» байты камеры не трогаются.
* **Особые порты**: записи только для клеток с особыми портами, свободные
  записи и байты 1532–1535 обнулены (Amiga не смотрит на счётчик и читает
  любую ненулевую запись, а байты 1532–1535 — как начало 11-го порта),
  счётчик (байт 1471) записывается верно — для совместимости с PC.
* **Байт 1445** (на PC — версия SpeedFix) обнуляется: Amiga его не читает.
* **Рамка**: дыра в «железе» по краю — ошибка. Murphy через край не пройдёт
  (его шаг ограничен экраном), но зонк или враг, ушедший за карту, вешает
  игру на Amiga.
* **Сохранение** — через временный файл; при первом сохранении за сеанс
  прежний `LEVELS.DAT` копируется в `LEVELS.DAT.bak`.

## Проверка

`level_test data/LEVELS.DAT` (запускается в CI) — на всех 111 уровнях дискеты:
приведение к правилам не меняет камеру, которую покажет игра, сохраняет
особые порты, до которых игра может дойти, не трогает карту и остальные поля;
сохранение без правок даёт файл байт в байт. Интерфейс проверялся скриптами
(`--script`: щелчки, клавиши, размер окна, закрытие окна, снимки экрана): рисование всеми инструментами,
особые порты, отмена, выделение и вставка, название, перестановка, импорт
перетаскиванием, экспорт, запуск уровня в игре.
