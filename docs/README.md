# Документация: Supaplex (Amiga, 1991)

1. [Дискета, загрузчик и порядок запуска](01-disk.md) — файлы, крэк CRYSTAL,
   распаковщик ByteKiller, интро, старт основной программы.
2. [Карта памяти](02-memory.md) — раскладка 512 КБ, переменные, списки объектов.
3. [Как игра использует железо](03-hardware.md) — copper-листы, блиттер,
   прерывания, ввод, звук.
4. [Логика игры](04-logic.md) — кодирование карты, кадр игры, Murphy, зонки и
   инфотроны, враги, диски, баги, взрывы, экран, меню, звук.
5. [Устройство порта и проверка точности](05-port.md) — транслятор, рантайм,
   модель времени, эталон на Musashi, `difftest`, фаззинг.
6. [Форматы данных](06-formats.md) — уровень, рекорды/игроки, ресурсы PHIL_02,
   графика.
